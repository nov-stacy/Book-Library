# Книжный сервис

Собственный сервис для читателей с функциональностью, похожей на LiveLib.
Название проекта пока рабочее.

## Цель

Создать удобное место для учёта прочитанных книг, поиска следующей книги
и сохранения впечатлений от чтения.

## Предложение для первой версии

Это начальная гипотеза; приоритеты уточним по опыту использования LiveLib.

- Каталог книг и поиск по названию и автору.
- Личная библиотека со статусами «Хочу прочитать», «Читаю», «Прочитано».
- Оценки и личные заметки о книгах.
- Страница книги с описанием и авторами.

## Следующие решения

1. Выяснить, что не устраивало в LiveLib и что хочется сохранить.
2. Выбрать платформу и основной пользовательский сценарий.
3. Сделать первый интерактивный прототип.
4. Определить источник книжных данных и требования к учётным записям.

Технологический стек пока не выбран.
