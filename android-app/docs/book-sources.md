# Источники книг

Конфигурация: `android-app/src/main/resources/book-sources.json`. Она упаковывается в APK и читается как Java resource — одинаково на Android и в JVM-тестах. Обновление реестра требует новой сборки; удалённой конфигурации нет.

`BookSources` загружает реестр, выбирает порядок и формат ISBN. `PublisherCatalog` читает обычные HTML-каталоги. Специальные API остаются адаптерами, зарегистрированными в `BookLookup` и `TitleBookSearch`, без цепочек условий по названию издательства.

## Подключённые издательства

Эксмо/Бомбора, АСТ (в том числе ОГИЗ и Бумажный фонарик), МИФ, 3dtotal и Синдбад дополнены источниками: Контэнт, Альпина, Питер, БХВ, Ad Marginem, Арт-Волхонка, Хоббитека, TASCHEN, Phaidon, Thames & Hudson, Laurence King, Search Press.

Азбука-Аттикус включена в реестр с `enabled: false`: при проверке 04.10.2026 сайт возвращал HTTP 502 или тайм-аут. Включать после проверки поиска и парсинга реальной карточки. ОГИЗ и Бумажный фонарик — псевдонимы АСТ; дублирующих запросов нет.

## Добавление обычного каталога

Добавить объект с уникальными `id`, `name`, `adapter: "html"`, `enabled: true`:

- `base`: HTTPS-адрес официального магазина.
- `titleSearch`, `isbnSearch`: относительные адреса поиска с `{query}`. Пустой адрес отключает соответствующий способ.
- `links`: CSS-селектор ссылок в результатах. `path`: регулярное выражение разрешённого пути карточки. Ссылки на другой домен не принимаются.
- `title` (по умолчанию `h1`), `author`, `isbn`: CSS-селекторы полей самой книги, без рекомендаций. Значение метатега берётся из `content`, остальных элементов — из текста.
- `cover`, `coverAttribute`: поле обложки; по умолчанию `meta[property=og:image]` и `content`. Относительные URL разрешаются относительно карточки, HTTP заменяется HTTPS.
- `prefixes`: проверенные префиксы издательства. Самый длинный совпавший префикс определяет первый источник.
- `isbnGroups`: длины групп ISBN для сайтов, требующих дефисы. Форматирование применяется только к указанным префиксам.
- `language`: `ru` или `en`, влияет на порядок поиска по названию.
- `aliases`: редакции общего издательского каталога, без дополнительных запросов.

Пустой автор или ISBN не выдумывается. Несколько разных ISBN в выбранном поле означают неоднозначное издание: результат по названию доступен для подтверждения, но для автоматической загрузки по ISBN не принимается. ISBN проверяется по контрольной сумме. Это актуально для многоязычных страниц TASCHEN. У Альпины в контрольной карточке был некорректный ISBN — он также не принимается.

Поле `adapter` выбирает обработчик формата, а не произвольный код. Для нового нестандартного JSON/API потребуется один новый адаптер; обычные HTML-каталоги добавляются записью в реестре.

## Ограничения и проверки

### Получение авторов

Все подключённые адаптеры читают авторов вместе с названием: из полей API, структурированных данных Book/Product или настроенных селекторов карточки издательства. Несколько авторов сохраняются через запятую, повторяющиеся имена удаляются. Для 3dtotal читается явное поле Author/Authors в описании API; если его нет, дополнительно проверяется HTML карточки. Издательство, авторы отзывов, редакторы и иллюстраторы не подставляются вместо автора. Если явных сведений нет, поле остаётся пустым.

При поиске по ISBN следующий подтверждённый источник может заполнить пустого автора, сохраняя уже найденное название. Поиск по-прежнему заканчивается на первой успешно загруженной обложке: отдельного обхода всех источников только ради автора нет.

Проверка 04.10.2026: точные имена на сохранённых карточках всех 12 HTML-каталогов, несколько авторов, исключение отзывов/редакторов и дополнение автора следующим источником. Последующая проверка на Infinix Note 50 описана ниже.

До четырёх источников одновременно; освободившийся поток сразу берёт следующий каталог, без ожидания пары. Общий бюджет поиска — 12 секунд. По названию на каталоги выделено до 9 секунд, оставшееся время доступно интернет-поиску; дополнительного 15-секундного ожидания нет. На один каталог — до 5 секунд, тайм-аут подключения/чтения — до 2,5 секунды и не больше оставшегося бюджета. Android и закрытие сетевых соединений могут немного увеличить фактическое время возврата.

Поиск по ISBN заканчивается при первой успешно декодированной обложке подтверждённого издания. По названию раннее завершение возможно при точном ISBN либо (если ISBN отсутствует) точном названии и совпадении введённого автора. Кандидат всегда показывается пользователю для подтверждения; отсутствие ISBN не доказывает совпадение издания. Если введён только заголовок, точное совпадение с доступной обложкой также показывается для подтверждения. Несколько точных вариантов могут завершить сбор результатов без ожидания всех источников.

Кнопка «Найти обложку» использует отдельный режим: проверяет загрузку изображений, исключает недоступные картинки и завершает поиск при первом проверенном точном совпадении. Ничего не записывается в книгу до подтверждения пользователя. В настройках массовый поиск обложек сохраняет строгую проверку ISBN.

Ответы каталогов и изображения кэшируются в памяти процесса на 30 минут (до 24 МБ и 256 записей); HTTP 404 — на 10 минут для конкретного URL. После двух тайм-аутов/ответов 429 или 5xx сайт пропускается на две минуты, затем проверяется снова. Отмена поиска не считается неисправностью сайта. Google использует отдельный существующий дисковый кэш и ограничения квоты. Все запросы прекращаются при завершении поиска; фонового продолжения нет.

На источник проверяется до трёх уникальных карточек. Заголовок HTTP `Accept` предпочитает HTML, иначе Shopify отдаёт JSON карточки вместо страницы. Ответы 429 не обходятся.

- `./gradlew testQaUnitTest assembleDebug lintDebug` — регрессии, сборка, Android lint.
- `HOMEBOOKS_LIVE_PUBLISHERS=1 ./gradlew testQaUnitTest --tests '*PublisherCatalogLiveTest'` — явная сетевая проверка новых издательств, без Google API. `HOMEBOOKS_PUBLISHER_FILTER` ограничивает проверку перечисленными названиями.
- `HOMEBOOKS_PUBLISHER_AUDIT=/path/to/captured/pages` включает офлайн-проверку сохранённых `<id>-book-search.html` через настоящий парсер.

После изменения конфигурации проверить: подходящую книгу, другое издание с тем же названием, несколько ISBN на странице, постороннюю ссылку и обложку. Доступность с компьютера не гарантирует доступность с телефона или другой сети.
