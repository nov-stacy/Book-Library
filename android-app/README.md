# Моя библиотека

Локальное Android-приложение для учёта домашней библиотеки. Оно помогает быстро
заносить бумажные книги по ISBN, хранить обложки, отмечать статус чтения,
раскладывать книги по коллекциям, типам и сериям, хранить выпуски журналов, вести годовой челлендж чтения и
создавать переносимые резервные копии.

Приложение работает без регистрации и собственного сервера. Сама библиотека
хранится на телефоне; интернет нужен только для поиска сведений о книгах и
обложек.

## Текущее состояние

- Платформа: Android 6.0 и новее (API 23+).
- Язык: Java 17.
- Данные: локальная SQLite-база и JPEG-обложки во внутренней памяти приложения.
- Сканирование: CameraX и встроенная модель ML Kit Barcode Scanning.
- Резервные копии: ZIP вручную или ежедневно в выбранную пользователем папку.
- Сервер приложения и учётная запись не требуются.

Типы книг — отдельный настраиваемый справочник с иконками и уникальными цветами.
Книге можно назначить один тип и независимо от него одну коллекцию.

## Сборка

Откройте папку `android-app` в Android Studio, дождитесь Gradle Sync, подключите
Android-телефон с разрешённой USB-отладкой и запустите приложение.

Из терминала:

```sh
JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home' \
  ./gradlew testQaUnitTest assembleDebug lintDebug
```

Готовый debug APK:

```text
build/outputs/apk/debug/android-app-debug.apk
```

Инструментальные проверки запускаются в отдельном пакете
`ru.homebooks.library.testbed` и не должны затрагивать настоящую библиотеку:

```sh
JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home' \
  ./gradlew connectedQaAndroidTest
```

Google Books используется только при наличии `googleBooksApiKey` в локальном
`local.properties` или переменной окружения `GOOGLE_BOOKS_API_KEY`. Секреты не
следует добавлять в Git.
