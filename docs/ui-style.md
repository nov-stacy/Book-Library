# Оформление «Тихой библиотеки»

Общие компоненты находятся в `Ui.java`. Сохранять компактность списка книг, читаемые цветные статусы и тёмные кнопки.

- Внешние поля экранов — 16 dp, внутренние поля карточек — 16 dp.
- Заголовки с навигацией собираются через `Ui.toolbar`, поиск — через `Ui.search`.
- Основные кнопки — минимум 52 dp по высоте, кнопки в компактных строках и иконки — минимум 48 dp.
- В шторке строки высотой минимум 60 dp, текст 17 sp; подписи и заголовок выровнены с текстом пунктов.
- Заголовки экранов — 23 sp, разделов — 20–21 sp, кнопки — 15 sp, текст списков — 15–16 sp, пояснения — 13–14 sp. Значения в полях — 16 sp.
- Описания настроек разделяются по смыслу переносами строк. Процент расположен справа от полосы прогресса.
- `Ui.action` — переход к действию с подписью слева, `Ui.primary` — сохранение/добавление, `Ui.textButton` — текстовое действие с полноценной областью нажатия.
- Модальные поля имеют горизонтальный отступ 24 dp внутри диалога; не вставлять EditText прямо в AlertDialog без `Ui.dialogField`.
- Не использовать фиксированную высоту для многострочных кнопок. Проверять длинные названия, шрифт 130% и ширину 320 dp.
- В списке книг: название, автор, затем коллекция слева и статус справа в нижней строке. Длинная коллекция сокращается в списке; полное название доступно в карточке.
- В карточке статус остаётся под автором. Ниже — компактная кнопка коллекции (минимум 48 dp), открывающая одиночный выбор с поиском, «Без коллекции» и созданием новой коллекции.

## Проверка

`StyleAuditTest` снимает реальные Android View в отдельном приложении `ru.homebooks.library.testbed`, проверяет высоту кнопок и обрезание их текста. Снимки находятся в `cache/style-audit` тестового приложения; их нужно забрать до его удаления. Камера проверяется как экран, без проверки распознавания.

`CoverLoaderTest` проверяет отмену с запоздавшим ответом, повторный запуск и сохранность существующих/добавленных вручную обложек.

Тесты запускаются только в варианте QA. Основное приложение и пользовательская библиотека не должны участвовать в инструментальных тестах.
