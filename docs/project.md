# Документация проекта «Моя библиотека»

Актуально на 6 октября 2026 года.

## 1. Назначение проекта

«Моя библиотека» — локальное Android-приложение для владельца домашней
библиотеки. Основной сценарий — пройти вдоль книжных полок, отсканировать ISBN
каждой книги и получить каталог, который удобно искать, фильтровать и переносить
между телефонами.

Приложение создаётся как спокойная и компактная альтернатива социальным книжным
сервисам. В нём нет публичного профиля, подписчиков, рекомендаций, оценок и
обязательной регистрации. Пользователь управляет собственными данными и сам
выбирает папку для резервных копий.

Главные принципы проекта:

- минимум действий при последовательном сканировании библиотеки;
- локальное хранение и работа с уже сохранёнными книгами без интернета;
- отсутствие автоматического изменения пользовательских данных;
- возможность добавить книгу даже без ISBN, автора или обложки;
- переносимость данных через ZIP и CSV;
- единый визуальный стиль «Тихой библиотеки»: тёплый фон, тёмные основные
  кнопки, крупные области нажатия и компактный список книг.

## 2. Что входит в приложение

### 2.1. Библиотека

Главный экран показывает все сохранённые книги. Для каждой книги отображаются
обложка, название, автор, коллекция и статус чтения.

Доступны:

- поиск по названию, автору и ISBN;
- фильтры «Все книги», «Читаю», «Хочу прочитать», «Прочитано», «Без обложки» и
  «Без коллекции»;
- сортировка по дате добавления, названию и автору в обоих направлениях;
- открытие полной карточки книги;
- выбор одной или нескольких книг;
- удаление выбранных книг с подтверждением;
- быстрый переход к добавлению следующей книги.

Выбранная сортировка сохраняется между запусками приложения. Удаление книги
удаляет её локальную обложку и связь с коллекцией.

### 2.2. Добавление книги по ISBN

ISBN можно получить двумя способами:

1. Отсканировать камерой штрихкод EAN-13.
2. Ввести ISBN-10 или ISBN-13 вручную.

Ручной ввод принимает пробелы и дефисы, проверяет контрольную цифру и приводит
ISBN-10 к ISBN-13. Обычный товарный штрихкод, не являющийся корректным ISBN, не
принимается.

После распознавания приложение:

1. Проверяет, нет ли такой книги в локальной библиотеке.
2. Если книги нет, ищет название и автора во внешних источниках.
3. Показывает одну редактируемую карточку.
4. Предлагает отдельно выбрать способ добавления обложки.
5. Сохраняет книгу только после нажатия основной кнопки.
6. В режиме последовательного сканирования возвращает камеру для следующей
   книги.

Найденная по ISBN книга не добавляется автоматически. Пользователь может
исправить название и автора, выбрать коллекцию, местонахождение, статус и дату
прочтения до сохранения.

Если книга уже существует и у неё есть обложка, повторный ISBN не создаёт дубль,
а сканирование продолжается. Если у существующей книги нет обложки, открывается
её карточка с предложением добавить обложку. Изменения записываются только после
нажатия «Сохранить».

### 2.3. Добавление книги без ISBN

Книгу можно добавить без ISBN. В этом случае приложение создаёт локальный
идентификатор. Обязательно только название; автор и обложка могут отсутствовать.

Книги без ISBN поддерживают:

- редактирование;
- статус чтения и дату прочтения;
- местонахождение;
- коллекцию;
- пользовательскую обложку;
- CSV-экспорт и ZIP-копию.

Автоматический поиск обложки для такой книги возможен по названию из карточки,
но результат всегда требует ручного подтверждения.

### 2.4. Поиск по названию

Если поиск по ISBN не дал сведений, пользователь вводит название и запускает
поиск вручную. Приложение показывает подходящие варианты, источник, автора,
сведения о совпадении ISBN и доступную обложку.

Выбор результата не сохраняет книгу сразу. Данные переносятся в карточку, где их
можно проверить и отредактировать.

### 2.5. Обложки

Обложка необязательна. Её можно:

- найти в интернете по ISBN, названию и автору;
- отсканировать как документ;
- выбрать из фотографий телефона;
- заменить при редактировании существующей книги;
- обработать перед сохранением.

Локальный редактор обложки позволяет:

- поставить четыре точки по углам книги;
- обрезать лишний фон;
- исправить перспективу;
- повернуть изображение на 90 градусов;
- предварительно посмотреть выровненный результат.

Фотография сначала хранится как черновик. Отмена редактирования не меняет уже
сохранённую обложку. После обработки пользователь возвращается в ту же карточку
со всеми введёнными полями; повторного подтверждения книги нет.

Если автоматический поиск не нашёл обложку, приложение показывает спокойное
сообщение с одной кнопкой «Вернуться». Книгу всё равно можно сохранить.

В настройках доступен массовый поиск недостающих обложек. Он:

- проверяет только книги с ISBN;
- пропускает книги, у которых уже есть читаемая обложка;
- показывает прогресс и процент;
- позволяет отменить поиск;
- не заменяет существующие обложки.

### 2.6. Карточка книги и редактирование

Карточка сохранённой книги содержит:

- ISBN, если он есть;
- обложку;
- название и автора;
- статус чтения;
- дату прочтения;
- коллекцию;
- местонахождение.

Название можно быстро скопировать. В режиме редактирования можно изменить
название, автора, обложку, местонахождение, дату прочтения и коллекцию. Статус
остаётся доступен на основной карточке. Несохранённые изменения можно отменить;
при выходе приложение предупреждает о потере черновика.

### 2.7. Статусы чтения

Поддерживаются четыре внутренних состояния:

- «Без статуса»;
- «Хочу прочитать»;
- «Читаю»;
- «Прочитано».

В основном фильтре отдельный пункт «Без статуса» не показывается. Статусы имеют
разные спокойные цвета, чтобы их можно было различать в списке и карточке.

Дата прочтения хранится отдельно от статуса. Её можно указать или убрать
вручную. Смена статуса не выдумывает дату автоматически.

### 2.8. Экран «Прочитано»

Раздел «Прочитано» показывает книги со статусом «Прочитано» и группирует их:

1. по году;
2. внутри года — по месяцу;
3. от более новых дат к более старым.

Книги без даты находятся в отдельной группе «Дата не указана». В разделе есть
поиск по названию, автору и ISBN. Нажатие открывает карточку книги.

### 2.9. Коллекции

Коллекция — пользовательская подборка книг, например «Любимые», «Учебные» или
«Вселенная Warcraft». Коллекция не является жанром или типом книги.

Книга может находиться только в одной коллекции. При выборе другой коллекции она
перемещается из прежней. Также книгу можно оставить без коллекции.

Доступны:

- создание коллекции;
- создание коллекции прямо во время выбора для книги;
- переименование и удаление коллекции;
- поиск коллекций по названию;
- сортировка по названию, количеству книг и времени создания;
- небольшие превью обложек в списке коллекций;
- поиск книг при добавлении в коллекцию;
- массовое добавление книг в открытую коллекцию;
- фильтр «Без коллекции» на главном экране.

Удаление коллекции не удаляет книги. При восстановлении старых данных, в которых
одна книга находилась сразу в нескольких коллекциях, приложение показывает эти
коллекции и просит выбрать одну.

### 2.10. Местонахождение

Для книги можно выбрать:

- «У меня»;
- «У родителей».

Если местонахождение отсутствует в старых или импортированных данных, книга
считается находящейся у пользователя. Местонахождение редактируется в карточке и
сохраняется в CSV и ZIP.

### 2.11. Удаление

Одну книгу можно удалить из её карточки. Несколько книг можно выбрать в общем
списке и удалить одновременно.

Перед удалением приложение показывает количество выбранных книг и просит
подтверждение. Удаление книги необратимо внутри приложения, но её можно вернуть
из ранее созданной резервной копии. Удаление книги из коллекции не удаляет её из
библиотеки.

## 3. Навигация

Боковая шторка открывается кнопкой меню и содержит четыре раздела:

- «Книги» — общий каталог;
- «Коллекции» — пользовательские подборки;
- «Прочитано» — история чтения по датам;
- «Настройки» — перенос данных, резервные копии и поиск обложек.

Кнопка «Назад» из камеры и экранов добавления возвращает пользователя в
библиотеку. Во время последовательного сканирования после сохранения следующая
камера открывается автоматически.

## 4. Пользовательские сценарии

### Сценарий A. Последовательно отсканировать домашнюю полку

1. На экране «Книги» нажать «＋ Книга».
2. Нажать «Начать сканирование».
3. Навести камеру на ISBN-штрихкод; при необходимости включить фонарик или
   коснуться изображения для фокусировки.
4. Проверить найденные название и автора.
5. Выбрать способ добавления обложки или оставить книгу без неё.
6. При необходимости выбрать коллекцию, местонахождение и статус.
7. Нажать «Сохранить и сканировать дальше».
8. Повторить для следующей книги.

### Сценарий B. ISBN найден, но обложки нет

1. Проверить название и автора в карточке.
2. Нажать «Найти в интернете», «Сканировать обложку» или «Выбрать фото».
3. Для фотографии выставить четыре угла, повернуть или выровнять изображение.
4. Нажать «Готово» и вернуться в ту же карточку.
5. Сохранить книгу.

### Сценарий C. Книга не найдена по ISBN

1. Ввести название и, если известно, автора.
2. Запустить поиск по названию.
3. Выбрать подходящее издание и проверить результат.
4. Либо не использовать поиск и заполнить карточку вручную.
5. Добавить обложку удобным способом и сохранить.

### Сценарий D. Добавить книгу без ISBN

1. Открыть добавление книги.
2. Выбрать «Добавить без ISBN».
3. Указать название; автора можно оставить пустым.
4. При желании добавить обложку, коллекцию, статус и местонахождение.
5. Сохранить книгу.

### Сценарий E. Разобрать книги без коллекции

1. На главном экране открыть фильтр.
2. Выбрать «Без коллекции».
3. Открыть книгу и перейти в редактирование.
4. Выбрать существующую коллекцию или создать новую прямо в окне выбора.
5. Сохранить карточку.

### Сценарий F. Отметить прочитанную книгу

1. Открыть карточку книги.
2. Выбрать статус «Прочитано».
3. В редактировании указать дату прочтения.
4. Открыть раздел «Прочитано» — книга появится в соответствующем году и месяце.

### Сценарий G. Перенести библиотеку на другой телефон

1. На старом телефоне открыть «Настройки» → «Создать копию ZIP».
2. Сохранить ZIP в доступную папку и перенести файл на новый телефон.
3. На новом телефоне установить приложение.
4. Открыть «Настройки» → «Восстановить из ZIP».
5. Проверить найденное количество книг и подтвердить восстановление.

ZIP — основной формат переноса, потому что он содержит коллекции и обложки.

### Сценарий H. Защититься от случайного удаления приложения

1. Открыть «Настройки» → «Ежедневная копия».
2. Выбрать пользовательскую папку, например Documents.
3. Дождаться создания первой копии.
4. Периодически проверять указанную в настройках дату последнего сохранения.

Копии находятся вне внутренней памяти приложения и остаются после его удаления.

## 5. Хранение и сохранность данных

### 5.1. Локальные данные

Библиотека хранится во внутреннем хранилище Android:

- SQLite-база `library.db`;
- обложки `files/covers/<ID книги>.jpg`;
- кэш сетевых ответов и временные черновики.

Данные не сбрасываются при обычном закрытии, перезапуске или обновлении APK поверх
установленного приложения. Удаление приложения или очистка его данных удаляет
внутреннюю библиотеку. Android-системное резервное копирование для приложения
отключено, поэтому для восстановления нужен созданный приложением ZIP.

### 5.2. Ручная ZIP-копия

Ручная копия содержит:

- точные данные всех книг;
- статусы и даты прочтения;
- местонахождение;
- коллекции, включая пустые;
- обложки;
- CSV для просмотра в табличной программе.

Текущий формат архива — версия 4. Внутри находятся `library.json`, `books.csv` и
`covers/<ID книги>.jpg`. Чтение архивов версий 1–4 поддерживается.

Перед восстановлением архив полностью проверяется. Ограничения защищают от
повреждённых и чрезмерно больших файлов: до 50 000 книг, до 10 000 коллекций,
до 16 МиБ на отдельный элемент и до 512 МиБ распакованных данных.

Восстановление дополняет библиотеку:

- существующие книги и пользовательские правки сохраняются;
- добавляются отсутствующие книги;
- локальной книге может быть дополнен отсутствующий ISBN;
- коллекции объединяются по названию без учёта регистра;
- существующая обложка не заменяется;
- для недостающих обложек после восстановления запускается отдельный поиск.

### 5.3. Ежедневная копия

Ежедневное сохранение включается только после выбора папки. Первая копия
создаётся сразу, следующие — не чаще одного раза в 24 часа. Android проверяет
расписание примерно раз в час, но может отложить выполнение из-за режима
энергосбережения, перезагрузки или ограничений фоновой работы.

Файлы называются `library-auto-ГГГГ-ММ-ДД-ЧЧММСС.zip`. Старые копии не удаляются
автоматически. Пользователь сам управляет свободным местом в выбранной папке.

Если запись не удалась, неполный файл удаляется, а в настройках показывается
ошибка. Отключение ежедневной копии отменяет расписание, но не удаляет уже
созданные ZIP-файлы.

### 5.4. CSV

CSV предназначен для просмотра и массового переноса текстовых данных. Он не
содержит обложки и коллекции.

Экспортируемые столбцы:

- `ISBN`;
- `Название`;
- `Автор`;
- `Дата добавления (UTC)`;
- `Статус`;
- `Местонахождение`;
- `ID книги`;
- `Дата прочтения`.

Файл создаётся в UTF-8 с BOM и запятыми. Значения экранируются для безопасного
открытия в электронных таблицах.

Импорт принимает UTF-8, запятую или точку с запятой, кавычки и многострочные
поля. Обязателен столбец `Название` или `title`. ISBN необязателен. Перед записью
весь файл проверяется; ошибка в строке не оставляет частично импортированные
данные.

Совпадения определяются по стабильному ID книги. У CSV, созданного приложением,
он сохраняет идентичность книг без ISBN. Если сторонний CSV не содержит ни ISBN,
ни `ID книги`, каждой строке назначается новый локальный ID, поэтому повторная
загрузка может создать дубли.

После импорта для книг с ISBN запускается поиск недостающих обложек. Названия,
авторы, статусы и существующие обложки сетевыми данными не заменяются.

## 6. Интернет и конфиденциальность

Без интернета работают:

- просмотр и поиск по уже сохранённой библиотеке;
- статусы, даты, коллекции и местонахождение;
- сканирование ISBN встроенной моделью;
- ручное добавление и редактирование;
- пользовательские фотографии обложек;
- экспорт ZIP и CSV;
- восстановление обложек, уже находящихся внутри ZIP.

Интернет требуется для:

- получения названия и автора по ISBN;
- поиска книги или обложки по названию;
- массового поиска недостающих обложек;
- чтения сведений со страницы издательства.

Во внешние каталоги передаются только данные, необходимые для запроса: ISBN,
название и иногда автор. Собственного сервера и пользовательской учётной записи
у проекта нет. Все соединения используют HTTPS; незашифрованный HTTP в приложении
запрещён.

## 7. Источники сведений о книгах

Приложение использует официальные каталоги издательств, Google Books,
Open Library и ограниченный резервный веб-поиск. Список HTML-каталогов хранится в
`app/src/main/resources/book-sources.json`, поэтому новый обычный каталог можно
добавить конфигурацией без цепочек условий в коде.

Основные правила поиска:

- до четырёх источников проверяются параллельно;
- общий бюджет обычного сетевого поиска — около 12 секунд;
- запрос отдельного каталога ограничен по времени;
- приоритет получает издательство, определённое по префиксу ISBN;
- автоматически принимается только издание с подтверждённым ISBN;
- изображение декодируется до использования;
- первая подходящая обложка останавливает дальнейший поиск;
- отмена операции прекращает оставшиеся запросы;
- временно нестабильный источник после повторных ошибок ненадолго пропускается;
- LiveLib не используется как автоматический источник.

Google Books включается при наличии API-ключа во время сборки. Ключ попадает в
APK, поэтому в Google Cloud для него следует настроить ограничения приложения и
квоты. Отсутствие ключа не мешает работе остальных источников.

Каталоги могут менять разметку, ограничивать частоту запросов или быть временно
недоступны. Поэтому сетевой поиск никогда не является условием сохранения книги.
Подробная конфигурация и список источников описаны в
[book-sources.md](book-sources.md).

## 8. Модель данных

### Книга

| Поле | Назначение |
|---|---|
| `id` | Стабильный ISBN-13 либо локальный UUID для книги без ISBN |
| `isbn` | ISBN-13 издания; может отсутствовать |
| `title` | Название; обязательное поле |
| `author` | Автор или несколько авторов; может отсутствовать |
| `addedAt` | Время добавления |
| `status` | Статус чтения |
| `location` | «У меня» или «У родителей» |
| `readOn` | Дата прочтения: год, год-месяц или полная дата |
| обложка | Отдельный JPEG-файл, связанный с `id` |

### Коллекция

Коллекция содержит уникальное имя и список ID книг. На уровне базы действует
ограничение: одна активная коллекция на книгу.

### Будущие типы книг

Идея классификации по содержанию — «Программирование», «Хобби», «Рисование»,
«Рукоделие», «Игры», «Художественная литература», «Артбуки», «Искусство» и
«Энциклопедии» — обсуждена, но отложена. В текущей модели данных этого поля нет.
Тип по содержанию не следует смешивать с пользовательскими коллекциями.

## 9. Техническая архитектура

Проект состоит из одного Android-модуля `app` и написан на Java 17.

Основные компоненты:

- `MainActivity` — каталог, поиск, фильтры, сортировка и массовый выбор;
- `AddBookActivity` — добавление, карточка и редактирование книги;
- `ScanActivity` — CameraX и распознавание EAN-13;
- `CoverEditActivity` — локальная обработка фотографии;
- `CollectionsActivity` и `CollectionUi` — коллекции и выбор книг;
- `ReadActivity` — история прочитанного;
- `SettingsActivity` — импорт, экспорт и операции с обложками;
- `LibraryStore` — SQLite и атомарная запись обложек;
- `LibraryBackup` и `DailyBackup` — ZIP-копии;
- `BookLookup`, `TitleBookSearch`, `PublisherCatalog` — сетевой поиск;
- `CoverLoader` — возобновляемая очередь недостающих обложек;
- `Ui` — общие элементы и визуальные правила.

Технические параметры:

- `minSdk 23`, `targetSdk 35`, `compileSdk 37`;
- Android Gradle Plugin 9.4.0;
- CameraX 1.4.2;
- ML Kit Barcode Scanning 17.3.0;
- ML Kit Document Scanner 16.0.0;
- jsoup 1.18.3;
- SQLite-схема версии 7.

Изменения библиотеки выполняются последовательно через один файловый executor.
Сетевые операции используют отдельный пул. Обложки записываются атомарно, чтобы
ошибка или остановка процесса не оставляла частичный JPEG.

## 10. Проверка проекта

Основная локальная проверка:

```sh
JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home' \
  ./gradlew testQaUnitTest assembleDebug assembleQa assembleQaAndroidTest lintDebug
```

Инструментальные проверки запускаются только в QA-пакете
`ru.homebooks.library.testbed`. Они проверяют SQLite, резервные копии, жизненный
цикл камеры, обработку обложки и реальные Android View, не открывая и не очищая
рабочую библиотеку пользователя.

Для функций камеры и внешнего сканера документов нужна ручная проверка на
реальном телефоне. Чек-лист находится в [device-checklist.md](device-checklist.md).

## 11. Известные ограничения

- Приложение предназначено только для Android.
- Сканер камеры распознаёт ISBN в штрихкоде EAN-13; ISBN-10 вводится вручную.
- Сетевой поиск зависит от доступности и разметки сторонних сайтов.
- Автоматический поиск не гарантирует обложку для редкого или регионального
  издания.
- Google Books ограничен внешней квотой проекта.
- Книга может находиться только в одной коллекции.
- CSV не переносит коллекции и обложки; для полного переноса нужен ZIP.
- Ежедневная копия является задачей Android и может быть выполнена позже ровных
  24 часов.
- Старые ежедневные ZIP-файлы не очищаются автоматически.
- У приложения нет синхронизации между устройствами и облачного аккаунта.

## 12. Термины

- **Библиотека** — все книги, сохранённые на устройстве.
- **Коллекция** — пользовательская подборка; у книги может быть только одна.
- **Статус** — этап чтения: хочу прочитать, читаю или прочитано.
- **Местонахождение** — где физически находится книга.
- **Тип по содержанию** — будущая классификация книги; пока не реализована.
- **Резервная копия** — ZIP со всеми данными и обложками.
- **CSV** — таблица с текстовыми данными без обложек и коллекций.
